# Faya docs

Working notes for building the Faya website. Read this folder before starting work in a new
session; update it whenever a decision is made or changed.

| File | What it holds |
| ---- | ------------- |
| [decisions.md](decisions.md) | Dated log of every product/design decision. Newest first. |
| [product/site-flow.md](product/site-flow.md) | The full visitor journey, step by step, with the status of each step. |
| [product/services.md](product/services.md) | The 4 categories (Film, Design, Commercial, Lab) and their services. |
| [product/requests-and-pricing.md](product/requests-and-pricing.md) | Request forms, pricing models, payment, retainer. **Postponed.** |
| [product/hidden-gift.md](product/hidden-gift.md) | The hidden gift game. **Postponed.** |
| [product/ideas.md](product/ideas.md) | Parked ideas for distinctive experiences (Contact as a screenplay, credits, light table…). Not decided. |
| [design/direction.md](design/direction.md) | Visual direction: references, fonts, colours, grain, motion. |
| [engineering/intro.md](engineering/intro.md) | How the built intro works (logo → eye → video). |
| [open-questions.md](open-questions.md) | Things waiting on the team: assets, answers, decisions. |

Source material from the team lives in the parent `Faya/` folder:

- `website-details.txt` — the original brainstorm (Persian).
- `business-plan.txt` — Brand Strategy inquiry form + pricing logic (Persian); the template
  for every service's request form.
- `steps-of-work.mov` — reference for the scroll "steps of work" section.
- `intro-desktop.mov`, `intro-mobile.mov` — the current intro video (to be replaced).

Coding rules are in [../CLAUDE.md](../CLAUDE.md); these docs don't repeat them.
